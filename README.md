# PWC-Call-Center-Dashboard-Analysis-Power-BI

## Project objective
Analyze agent performance and key call center metrics and identify trends in call handling efficiency and customer satisfaction,visualize call volumes by time and day to optimize staffing schedules

## Dataset used
- <a href="https://github.com/AnushaTentu30/PWC-Call-Center-Dashboard-Analysis-Power-BI/blob/main/PWC%20Reports.pbix">Dataset</a>

## Questions(KPI)

-Agent efficiency and performance

-Call resolution and abandonment rates

-Average call handling time

-Customer satisfaction level (by count and percentage)

-Call volume by hour and by day

## Process

-Identified peak hours and days with highest call volumes to help in workforce planning
-Highlighted agents with high and low performance for targeted training
-Monitored trends in satisfaction levels to inform quality assurance strategies

## Project output
An interactive Power BI dashboard with slicers and visualizations for dynamic exploration of call center operations and performance.
